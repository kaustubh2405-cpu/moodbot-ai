# 🎭 MoodBot AI

MoodBot AI is a multi-personality AI chatbot built with Python, LangChain, Groq and Streamlit. Pick a mood, or let the bot detect yours, and the whole app changes: the personality, the tone of the replies and the colours of the interface. The project demonstrates practical LLM integration, prompt engineering, streaming responses, usage limiting and end-to-end deployment of an AI app.

🔗 **Live Demo:** https://moodbot-ai-hgamojebjlxp7gs8zhbgzi.streamlit.app


 



## 📌 Overview
Most chatbots answer in one fixed tone. MoodBot AI lets the user choose how it talks. Each personality is defined by its own system prompt, and the interface theme changes with the selected mood. Replies are generated by the Groq model `openai/gpt-oss-120b` and streamed word by word for a fast, natural feel.

## ✨ Features
- **13 personalities:** Funny, Rude & Sarcastic, Sad, Professional, Motivational Coach, Study Buddy, Caring Friend, Detective, Pirate, Zen Guide, Gen-Z Buddy, Shakespeare, and a Custom mode where users write their own personality
- **Auto mood detection:** the bot reads each message and switches to the personality that fits
- **Mood-themed UI:** background glow, header card and chat box change colour with every mood
- **Creativity slider:** control the model temperature from focused to wildly creative
- **Streaming replies:** responses appear word by word in real time
- **Conversation memory:** the bot remembers recent messages within a chat
- **Usage limit:** a per-session message cap, a cooldown between messages and an input length limit to protect API quota
- **Chat management:** start a new chat, reopen past chats from the sidebar, clear history and download any conversation as a text file
- **Private by design:** chat history is kept per visitor session, so users never see each other's chats
- **Secure API key handling** with Streamlit Secrets

## 🛠️ Tech Stack
- **Language:** Python
- **LLM Framework:** LangChain (langchain-core, langchain-groq)
- **LLM Provider:** Groq API (`openai/gpt-oss-120b`)
- **Frontend / UI:** Streamlit with custom CSS
- **Configuration:** python-dotenv and Streamlit Secrets
- **Deployment:** Streamlit Community Cloud
- **Version Control:** Git and GitHub

## ⚙️ How It Works
1. The user picks a personality in the sidebar, or turns on auto-detect.
2. With auto-detect on, a quick low-temperature model call chooses the best matching mood.
3. The app builds a prompt from the personality instructions plus the recent chat history.
4. LangChain sends it to the Groq model and streams the reply into the chat window.
5. The conversation is saved in the session so it can be reopened or downloaded.

## 🚀 Run Locally
1. Clone the repo: `git clone https://github.com/kaustubh2405-cpu/moodbot-ai.git`
2. Go to the folder: `cd moodbot-ai`
3. Install dependencies: `pip install -r requirements.txt`
4. Create a `.env` file containing: `GROQ_API_KEY=your_key_here`
5. Start the app: `streamlit run moodbotai.py`

## ☁️ Deployment
The app is deployed on Streamlit Community Cloud. The API key is stored in Streamlit Secrets and is never committed to the repository.

## ⚙️ Configuration
You can change these values at the top of `moodbotai.py`: `MAX_MESSAGES`, `COOLDOWN_SECONDS`, `MAX_INPUT_CHARS`, `HISTORY_WINDOW` and `MODEL_NAME`.
